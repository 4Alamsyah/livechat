Acme Inc. — Example Website

This page pretends to be a totally unrelated third-party website. It embeds the Live Support widget the same way any customer site would: a single <script> tag pointing at the Laravel app.

How to use this page
  1. Make sure the Laravel app is running (e.g. php artisan serve) and reachable at the URL below.
  2. Run php artisan reverb:start in another terminal so real-time chat/calls work.
  3. Open this page, click the chat bubble in the bottom-right corner, and say hello.
  4. Log into /agent/dashboard as an agent in another browser/tab to reply, or accept a call.

To genuinely test cross-origin behaviour (like a real third-party site would), serve this folder from a different port, e.g. php -S localhost:9000 -t public/demo, while Laravel runs on localhost:8000.
